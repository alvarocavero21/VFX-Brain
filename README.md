# VFX-Brain

Vault de conocimiento técnico para Houdini, Nuke, ComfyUI, Unreal Engine y pipeline general.

## Estructura
- 00_Inbox: notas rápidas sin clasificar
- 01_Houdini a 03_ComfyUI: conocimiento técnico por herramienta
- 04_Pipeline_General: workflows, setup de máquinas, render farm
- 05_Projects: proyectos activos
- 06_Problemas_Resueltos: base de conocimiento transversal, la más valiosa
- 07_Unreal_Engine: UE 5.8 para escenas cinemáticas realistas (empezar por 00_MOC_Unreal)
- 99_Templates: plantillas reutilizables
