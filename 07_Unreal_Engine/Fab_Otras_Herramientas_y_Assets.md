# Fab: otras herramientas y assets útiles para realismo

## Qué es Fab
Marketplace unificado de Epic (sustituye al Unreal Marketplace, Quixel Bridge store, Sketchfab store y ArtStation Marketplace). Se accede desde la web o desde el **panel Fab dentro del editor** (plugin Fab).

## Megascans (Quixel)
- Gratis para todos hasta fin de 2024; **lo que reclamé entonces es mío para siempre** → revisar mi biblioteca de Fab antes de comprar nada.
- Desde 2025 la mayoría es de pago, pero hay una **selección gratuita curada de >1.500 assets** (assets 3D, plantas, árboles, superficies, decals e imperfecciones) para cualquier motor.
- Prioridad de uso para realismo: **surfaces + decals + imperfecciones** (manchas, grietas, charcos, hojas sueltas) antes que assets hero.

## Otras fuentes de assets
- **Packs gratuitos mensuales de Fab**: reclamar siempre (rotan cada ~2 semanas/mes). Hábito: revisar al inicio de cada mes.
- **KitBash3D plugin**: el plugin es gratis (kits de pago), shaders/LODs/colisión ya preparados → útil para ciudades/sci-fi.
- **PolyCraft Visuals** (vendedor en Fab): plugins de editor para cámara/luces, color grading, limpieza de proyecto y render en 1 clic (evaluar, no imprescindible).
- **Ultra Dynamic Sky** (Everett Gunther): cielo/clima dinámico muy popular. Para cinemática controlada prefiero el sistema nativo (Sky Atmosphere + Volumetric Clouds) + Easy tools, pero UDS es una alternativa todo-en-uno. *Verificar versión 5.8 en Fab.*

## Criterio de compra (para no gastar dinero en tonterías)
1. ¿Resuelve algo que **en Houdini tardaría >1 sesión**? → considerar.
2. ¿Tiene build para **5.8**? → obligatorio.
3. ¿El autor publica tutoriales/soporte? (Faucher sí).
4. ¿Lo voy a usar en un shot del roadmap ([[00_MOC_Unreal]])? Si no, no.
